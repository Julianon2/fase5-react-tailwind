Ejercicio 1

Página NotFound para rutas que no existen

Ahora mismo, si alguien escribe localhost:5173/algo-que-no-existe, la página se ve completamente en blanco (solo Navbar y Footer, sin contenido en el medio) — sin explicación. Se agrega una ruta "comodín" que atrapa cualquier URL no reconocida.

1

Crear src/NotFound.jsx:

frontend-react/src/NotFound.jsxcontenido completo
import { Link } from 'react-router-dom'

function NotFound() {
  return (
    <div className="flex flex-col items-center justify-center text-center gap-4 py-20">
      <h1 className="text-5xl font-extrabold text-texto-dim">404</h1>
      <p className="text-texto-dim">Esta página no existe.</p>
      <Link to="/" className="text-verde font-bold underline">
        Volver al inicio
      </Link>
    </div>
  )
}

export default NotFound
2

En App.jsx, importar NotFound y agregar una última <Route> con path="*":

frontend-react/src/App.jsxantes
import { Routes, Route } from 'react-router-dom'
import Navbar from "./Navbar";
import Footer from "./Footer.jsx";
import Home from "./Home.jsx";
import Productos from "./Productos.jsx";

function App() {
  return (
    <main className="min-h-screen max-w-6xl mx-auto px-6 py-10 flex flex-col justify-between gap-10">
      <Navbar />
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/productos" element={<Productos />} />
      </Routes>
      <Footer />
    </main>
  );
}

export default App;

ParteQué hace
path="*"El asterisco significa "cualquier URL que no haya coincidido con ninguna Route anterior"
Debe ir al finalReact Router evalúa las rutas en orden — si "*" fuera la primera, atraparía todo, incluida "/" y "/productos"
✅Cómo verificar: escribir manualmente localhost:5173/paginaquenoexiste en la barra de direcciones — debe aparecer "404 — Esta página no existe" con un link para volver al inicio. Las rutas "/" y "/productos" deben seguir funcionando normal.

Ejercicio 3

Navegar con código, sin usar Link

A veces se necesita navegar después de que pase algo (ej. tras enviar un formulario) — no al hacer clic en un link. Para eso existe useNavigate.

1

En Home.jsx, agregar un botón que lleve a Productos usando código en vez de un <Link>:

frontend-react/src/Home.jsxantes
function Home() {
  return (
    <div className="flex flex-col items-center justify-center text-center gap-4 py-20">
      <h1 className="text-4xl font-extrabold text-verde">
        Bienvenido a TechStore Pro
      </h1>
      <p className="text-texto-dim max-w-md">
        Tecnología de calidad, al mejor precio. Explora nuestro catálogo de productos.
      </p>
    </div>
  );
}

export default Home;
frontend-react/src/Home.jsxdespués — reemplazar todo el archivo
import { useNavigate } from 'react-router-dom'

function Home() {
  const navegar = useNavigate()

  return (
    <div className="flex flex-col items-center justify-center text-center gap-4 py-20">
      <h1 className="text-4xl font-extrabold text-verde">
        Bienvenido a TechStore Pro
      </h1>
      <p className="text-texto-dim max-w-md">
        Tecnología de calidad, al mejor precio. Explora nuestro catálogo de productos.
      </p>
      <button
        onClick={() => navegar("/productos")}
        className="bg-verde text-white py-2 px-6 rounded-lg font-bold"
      >
        Ver catálogo
      </button>
    </div>
  );
}

export default Home;
ParteQué hace
useNavigate()Hook que devuelve una función para cambiar de página por código
navegar("/productos")Llamarla con una ruta navega ahí mismo — igual que <Link to="/productos">, pero disparado desde cualquier función de JavaScript, no solo un clic directo en un link
💡¿Cuándo usar useNavigate en vez de <Link>? Cuando la navegación depende de una condición o pasa después de otra acción — por ejemplo, ir a "Mis Pedidos" automáticamente después de que un pago se confirme con éxito (eso se verá en sesiones futuras de la fase).
✅Cómo verificar: en la página Home, hacer clic en "Ver catálogo" debe llevar a /productos igual que si se hubiera hecho clic en el link del navbar.
