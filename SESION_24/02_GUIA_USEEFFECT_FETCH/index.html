Paso 1 · Backend

Levantar el servidor de la Fase 3

Antes de tocar React, hay que confirmar que el backend responde — si no está corriendo, nada de lo de hoy va a funcionar.

1

Abrir una terminal nueva (sin cerrar la que tiene npm run dev del frontend) y navegar hasta la carpeta backend/ de plantilla_proyecto. Correr:

terminal — dentro de backend/
npm run dev
Si el comando no existe o da error, revisa el package.json del backend — puede llamarse npm start en vez de npm run dev, según cómo quedó configurado en la Fase 3.
2

Confirmar en la terminal que el servidor arrancó correctamente, normalmente mostrando algo como "Servidor corriendo en el puerto 3000" o similar, y que la conexión a MongoDB Atlas fue exitosa.

3

Abrir una pestaña nueva del navegador y visitar directamente:

navegador
http://localhost:3000/api/productos
Cómo verificar: debe aparecer un array en formato JSON con los productos guardados en la base de datos — con campos id, icono, nombre, descripcion, precio, imagen. Si ves esto, el backend está listo.
Si la base de datos está vacía (array []), el resto de la guía va a funcionar igual, pero el catálogo se va a ver sin tarjetas. No es un error de código.

Paso 4 · Ajuste

ProductCard con los campos reales

El backend real no tiene campo stock (era solo del ejercicio de S22) — y sí tiene icono, que nunca se había usado. Se ajusta ProductCard.jsx a los datos reales.

1

En ProductCard.jsx, quitar la línea del stock y agregar el icono antes del nombre:

frontend-react/src/ProductCard.jsxantes
function ProductCard(props) {
  return (
    <div className="flex flex-col gap-2 p-4 rounded-xl shadow-md bg-white">
      <img src={props.imagen} className="rounded-lg" />
      <h3 className="font-bold text-lg">{props.nombre}</h3>
      <p className="text-texto-dim text-sm">{props.descripcion}</p>
      <p className="text-verde font-extrabold">{props.precio}</p>
      <p className="text-texto-dim text-xs">Stock: {props.stock} unidades</p>
    </div>
  )
}
frontend-react/src/ProductCard.jsxdespués
function ProductCard(props) {
  return (
    <div className="flex flex-col gap-2 p-4 rounded-xl shadow-md bg-white">
      <img src={props.imagen} className="rounded-lg" />
      <h3 className="font-bold text-lg">{props.icono} {props.nombre}</h3>
