Paso 1 · Sesión

Crear AuthContext.jsx

El Context que maneja quién inició sesión — migra la lógica de localStorage que ya existía en el frontend viejo, pero conectada a React.

1

Levantar los 2 servidores, cada uno en su propia terminal (si ya estaban corriendo desde antes, no hace falta reiniciarlos):

terminal 1 — dentro de backend/
npm run dev
terminal 2 — dentro de frontend-react/
npm run dev
💡Hoy no se usa ningún endpoint nuevo del backend — pero debe estar corriendo igual, porque la página Productos (S24) sigue necesitándolo para cargar el catálogo mientras navegas.
✅Cómo verificar: localhost:5173 abre la app con el catálogo cargando normal en /productos, sin el mensaje de "No se pudo conectar al servidor".
2

Crear src/AuthContext.jsx con este contenido completo:

frontend-react/src/AuthContext.jsxcontenido completo
import { createContext, useState } from "react";

export const AuthContext = createContext();

export function AuthProvider({ children }) {
  const [usuario, setUsuario] = useState(
    localStorage.getItem("usuario-nombre")
  );

  function login(nombre, token, rol) {
    localStorage.setItem("token", token);
    localStorage.setItem("usuario-nombre", nombre);
    localStorage.setItem("usuario-rol", rol);
    setUsuario(nombre);
  }

  function logout() {
    localStorage.clear();
    setUsuario(null);
  }

  return (
    <AuthContext.Provider value={{ usuario, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}
ParteQué hace
export const AuthContext = createContext()Crea el canal — se exporta para poder usarlo con useContext en otros archivos
export function AuthProvider({ children })El componente que transmite el valor — children es todo lo que quede envuelto adentro
useState(localStorage.getItem(...))Si ya había sesión guardada, arranca con ese nombre — no se pierde al recargar la página
login(nombre, token, rol)Guarda en localStorage Y actualiza el estado de React al mismo tiempo
logout()Limpia localStorage por completo y pone usuario en null
value={{ usuario, login, logout }}Lo que viaja por el canal — cualquier componente podrá leer estas 3 cosas con useContext
⚠️Formatea el archivo con Shift + Alt + F si la indentación queda desordenada al pegar.
💡¿Cuándo se ve AuthContext en pantalla? A diferencia de CartContext (que hoy mismo se conecta al Navbar, en el Paso 4), AuthContext queda listo pero sin usar visualmente — no hay todavía ningún formulario real que llame a login(). Esa conexión llega en la Sesión 30, cuando se migre la página de Login y login() se llame de verdad tras un POST /api/auth/login exitoso. Hoy solo se prueba que el archivo compile y funcione, por consola del navegador.
✅Cómo verificar: todavía no hay nada que ver en el navegador — AuthContext.jsx no se está usando en ningún lado aún. Solo confirma que no hay líneas rojas de sintaxis en VS Code.
Paso 2 · Carrito

Crear CartContext.jsx

Mismo patrón que el Paso 1 — esta vez migrando leerCarrito() y guardarCarrito() del frontend viejo.

1

Crear src/CartContext.jsx con este contenido completo:

frontend-react/src/CartContext.jsxcontenido completo
import { createContext, useState } from "react";

export const CartContext = createContext();

export function CartProvider({ children }) {
  const [items, setItems] = useState(() => {
    const guardado = localStorage.getItem("carrito");
    return guardado ? JSON.parse(guardado) : [];
  });

  function agregarAlCarrito(producto) {
    const nuevo = [...items, producto];
    setItems(nuevo);
    localStorage.setItem("carrito", JSON.stringify(nuevo));
  }

  function quitarDelCarrito(indice) {
    const nuevo = items.filter((_, i) => i !== indice);
    setItems(nuevo);
    localStorage.setItem("carrito", JSON.stringify(nuevo));
  }

  function vaciarCarrito() {
    setItems([]);
    localStorage.removeItem("carrito");
  }

  return (
    <CartContext.Provider value={{ items, agregarAlCarrito, quitarDelCarrito, vaciarCarrito }}>
      {children}
    </CartContext.Provider>
  );
}
ParteQué hace
useState(() => {...})Forma "perezosa" de useState — la función de adentro solo se ejecuta una vez, al crear el componente
guardado ? JSON.parse(guardado) : []Si ya había un carrito guardado, lo convierte de texto a array; si no, empieza vacío
agregarAlCarrito(producto)Crea un array nuevo con todo lo anterior más el producto, actualiza React y localStorage juntos
quitarDelCarrito(indice)Crea un array nuevo sin el elemento de esa posición, usando .filter()
vaciarCarrito()Deja items en un array vacío y borra la clave "carrito" de localStorage
💡quitarDelCarrito y vaciarCarrito no se usan todavía en esta guía — quedan listos para cuando se migre la página Carrito completa en S31.
✅Cómo verificar: sin líneas rojas en VS Code dentro de CartContext.jsx.

import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { BrowserRouter } from 'react-router-dom'

AuthProvider y CartProvider anidadosApp necesita acceso a ambos Contexts — por eso uno envuelve al otro, y ambos envuelven a App
Por dentro de BrowserRouterEl orden entre estos 3 no afecta el funcionamiento — se mantiene BrowserRouter más afuera por ser el más antiguo (S25)
✅Cómo verificar: en localhost:5173, la app sigue viéndose exactamente igual que antes — los Providers todavía no cambian nada visible, solo habilitan lo que viene en el Paso 4. Sin errores en consola ni en la terminal.

Agregar el import de useContext y CartContext, leer items, y mostrar el contador junto al botón:

frontend-react/src/Navbar.jsxdespués — reemplazar todo el archivo
import { Link, useLocation } from 'react-router-dom'
import { useContext } from 'react'
import { CartContext } from './CartContext.jsx'

function Navbar() {
  const ubicacion = useLocation()
  const { items } = useContext(CartContext)
  return (
    <nav className="flex items-center justify-between px-8 py-4 bg-white border-b border-slate-200">
      <div className="text-xl font-extrabold text-verde">TechStore Pro</div>
      <ul className="hidden md:flex gap-6 text-sm font-semibold text-texto-dim">
        <li>
          <Link
            to="/"
            className={ubicacion.pathname === "/" ? "text-verde font-extrabold" : ""}
          >
            Inicio
          </Link>
        </li>
        <li>
          <Link
            to="/productos"
            className={ubicacion.pathname === "/productos" ? "text-verde font-extrabold" : ""}
          >
            Productos
          </Link>
        </li>
        <li>Nosotros</li>
        <li>Contacto</li>
      </ul>
      <div className="flex items-center gap-4">
        <span className="text-sm font-semibold text-texto-dim">
          Carrito: {items.length}
        </span>
        <button className="bg-verde text-white py-2 px-5 rounded-lg font-bold text-sm">
          Ingresar
        </button>
      </div>
    </nav>
  );
}

export default Navbar;
ParteQué hace
useContext(CartContext)Lee el valor transmitido por CartProvider — funciona porque Navbar está dentro de él (Paso 3)
{ items }Extrae el array de productos del carrito, directamente del Context
items.lengthCuántos productos hay — se actualiza solo, sin código manual, cuando el carrito cambie
<div className="flex items-center gap-4">Nuevo contenedor que agrupa el contador y el botón, para que queden en fila
