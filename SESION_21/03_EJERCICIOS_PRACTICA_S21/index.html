Ejercicios de Práctica — Componentes y JSX

SENA ADSO · Ficha 3229944 · Septiembre 2026

Estos ejercicios son opcionales, para reforzar lo aprendido en 02_GUIA_COMPONENTES_JSX.html si sobra tiempo en la sesión. No introducen conceptos nuevos.
¿Qué practicamos aquí?
El mismo patrón de la guía, aplicado a un segundo componente

En la guía 02 se separó el navbar en Navbar.jsx. Aquí se repite exactamente el mismo proceso (crear archivo → función → export default → import → usar como etiqueta), esta vez con el <footer> — para que el patrón quede automatizado.

Ejercicio 1
Crear src/Footer.jsx con el footer movido desde App.jsx
Ejercicio 2
Exportarlo e importarlo, igual que se hizo con Navbar
Ejercicio 3
App.jsx queda ensamblando 2 componentes: Navbar y Footer
Ejercicio 1

Crear src/Footer.jsx

Mismo primer paso que con el navbar: crear el archivo, y mover el bloque <footer>...</footer> de App.jsx hacia adentro de una función.

1

Crear el archivo src/Footer.jsx (al lado de App.jsx y Navbar.jsx).

2

En App.jsx, cortar (Ctrl+X) el bloque completo <footer>...</footer> y pegarlo (Ctrl+V) dentro de Footer.jsx:

Bloque que se mueve de App.jsx a Footer.jsxcortar y pegar
<footer className="flex flex-col md:flex-row justify-between items-center gap-2 md:gap-0 p-6 bg-texto text-white">
  <p>© 2026 TechStore Pro</p>
  <p className="text-sm">Hecho con Tailwind CSS</p>
</footer>
Si tu footer quedó distinto (por ejemplo sin el flex-col md:flex-row del Ejercicio 3 de S20), mueve el tuyo real.
3

Envolver ese bloque en una función llamada Footer:

frontend-react/src/Footer.jsxcontenido completo (sin export todavía)
function Footer() {
  return (
    <footer className="flex flex-col md:flex-row justify-between items-center gap-2 md:gap-0 p-6 bg-texto text-white">
      <p>© 2026 TechStore Pro</p>
      <p className="text-sm">Hecho con Tailwind CSS</p>
    </footer>
  )
}
Formatea el archivo con Shift + Alt + F si la indentación queda desordenada al pegar.
Cómo verificar: el archivo Footer.jsx existe, con la función Footer y el JSX del footer adentro — todavía sin export default, eso es el Ejercicio 2.
Ejercicio 2

export default e import

Exactamente el mismo mecanismo del Paso 2 y 3 de la guía — esta vez sin ejemplo resuelto, para practicarlo de memoria.

1

Al final de Footer.jsx, agregar la línea que lo exporta como default — usa el mismo formato que viste en Navbar.jsx:

frontend-react/src/Footer.jsxagregar al final
export default Footer
RecordatorioRegla
El nombre después de export defaultDebe coincidir exactamente con function Footer() — mismas mayúsculas
2

En App.jsx, junto al import Navbar from './Navbar.jsx' que ya existe, agregar una segunda línea de import para Footer:

frontend-react/src/App.jsxagregar
import Navbar from './Navbar.jsx'
import Footer from './Footer.jsx'

function App() {
  ...
Cómo verificar: ni Footer.jsx ni App.jsx deben mostrar líneas rojas en VS Code — el import ya está listo para usarse en el Ejercicio 3.
Ejercicio 3

App.jsx ensamblando 2 componentes

Último paso: reemplazar el bloque viejo del footer (donde quedó el espacio vacío tras cortarlo) por <Footer />.

1

En el espacio vacío dentro del return (...) de App.jsx donde antes estaba el <footer>, escribir:

frontend-react/src/App.jsxescribir en el espacio vacío
<Footer />

App.jsx completo debe quedar ensamblando ambos componentes:

frontend-react/src/App.jsxcómo queda
import Navbar from './Navbar.jsx'
import Footer from './Footer.jsx'

function App() {
  return (

  <main className="max-w-6xl mx-auto px-6 py-10 flex flex-col gap-10">

    <Navbar />

    <section className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
      {/* Tarjetas — sin cambios */}
    </section>

    <Footer />

  </main>
  )
}

export default App
Cómo verificar: en localhost:5173, el footer se ve exactamente igual que antes. App.jsx ya no tiene ni <nav> ni <footer> escritos directamente — solo los usa como <Navbar /> y <Footer />.
Recordatorio: este ejercicio (Footer.jsx) es de práctica — se puede dejar en el proyecto, no afecta el entregable obligatorio de la guía 02 (Navbar.jsx).
