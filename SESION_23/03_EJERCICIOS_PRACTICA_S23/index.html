Ejercicio 1

Agregar el límite al contador

En la apertura se mencionó que el botón "−" de Contador.jsx no tiene límite y puede bajar a negativos. Aquí se corrige eso, y de paso se retira <Contador /> de App.jsx — ya cumplió su propósito de práctica.

1

En Contador.jsx, modificar el onClick del botón "−":

frontend-react/src/Contador.jsxantes
onClick={() => setCuenta(cuenta - 1)}
frontend-react/src/Contador.jsxdespués
onClick={() => setCuenta(cuenta > 0 ? cuenta - 1 : 0)}
ParteQué hace
cuenta > 0La condición — pregunta si el valor actual es mayor que 0
? cuenta - 1Si la condición es verdadera, resta 1 normalmente
: 0Si la condición es falsa (ya está en 0), se queda en 0 en vez de bajar más
💡Esto se llama operador ternario — una forma corta de escribir un if/else en una sola línea: condición ? valorSiVerdadero : valorSiFalso.
✅Cómo verificar: con <Contador /> todavía visible en localhost:5173 (sigue ahí desde la guía 02), el botón "−" ya no debe bajar de 0 — se queda ahí sin importar cuántas veces hagas clic.
2

Una vez verificado el límite, en App.jsx borrar la línea <Contador /> y su import. El archivo Contador.jsx puede quedarse en src/ sin usarse, no causa ningún error.

💡No borrar Contador.jsx del todo — sirve como referencia rápida de la mecánica de useState si la necesitas repasar más adelante.
✅Cómo verificar: el catálogo queda igual que al final de la guía 02, pero sin la tarjeta del contador encima.
Ejercicio 2

Contador de resultados del buscador

Mostrar cuántos productos coinciden con la búsqueda actual, al lado del input — útil para que el usuario sepa, de un vistazo, cuántos resultados hay.

1

En App.jsx, localizar el <input> del buscador — en tu proyecto está justo después de <Navbar />:

frontend-react/src/App.jsxantes
<Navbar />
<input
  type="text"
  placeholder="Buscar producto..."
  value={busqueda}
  onChange={(e) => setBusqueda(e.target.value)}
  className="w-full max-w-md px-4 py-2 border-2 border-slate-200 rounded-lg"
/>
<section className="grid ...">

Envolver el <input> y un nuevo <p> en un <div> con flex, para que queden lado a lado:

frontend-react/src/App.jsxdespués
<Navbar />
<div className="flex items-center gap-3"> // nuevo: envuelve lo de abajo
  <input
    type="text"
    placeholder="Buscar producto..."
    value={busqueda}
    onChange={(e) => setBusqueda(e.target.value)}
    className="w-full max-w-md px-4 py-2 border-2 border-slate-200 rounded-lg"
  /> // sin cambios, solo se movió adentro
  <p className="text-sm text-texto-dim whitespace-nowrap">
    {productos.filter((p) => p.nombre.toLowerCase().includes(busqueda.toLowerCase())).length} producto(s) encontrado(s)
  </p> // nuevo
</div>
<section className="grid ...">
🟡En amarillo, lo que es nuevo (el <div> que envuelve y el <p> del contador) — el <input> no cambia, solo queda adentro del nuevo <div>.
ParteQué hace
<div className="flex items-center gap-3">Pone el input y el texto en fila, alineados verticalmente al centro, con separación entre ambos
whitespace-nowrapEvita que el texto "producto(s) encontrado(s)" se parta en dos líneas si el espacio es angosto
productos.filter(...)El mismo filtro del Paso 3 de la guía, repetido aquí para contar
.lengthCuenta cuántos elementos quedaron después de filtrar
💡Aquí se repite la misma condición de .filter() dos veces (una para contar, otra para dibujar las tarjetas) — funciona bien para esta práctica. Más adelante, cuando se vea cómo evitar cálculos repetidos, se aprenderá a guardar el resultado filtrado una sola vez en una variable y reutilizarlo.
✅Cómo verificar: el input y el texto "producto(s) encontrado(s)" quedan en la misma fila. Al escribir "mouse", debe decir "1 producto(s) encontrado(s)". Al borrar el texto, debe decir "4 producto(s) encontrado(s)".
Ejercicio 3

Mensaje cuando no hay resultados

Ahora mismo, buscar algo que no existe deja el catálogo completamente vacío y en blanco — mejor mostrar un mensaje claro.

1

En App.jsx, justo después del </section> del catálogo, agregar un mensaje condicional:

frontend-react/src/App.jsxagregar después de </section>
{productos.filter((p) => p.nombre.toLowerCase().includes(busqueda.toLowerCase())).length === 0 && (
  <p className="text-center text-texto-dim py-10">
    No se encontraron productos con ese nombre.
  </p>
)}
ParteQué hace
... .length === 0Verdadero si el filtro no encontró ningún producto
condición && (JSX)Si la condición es verdadera, muestra el JSX; si es falsa, no muestra nada
💡condición && (...) es un patrón muy común en React para mostrar algo solo cuando se cumple una condición, sin necesidad de un if completo dentro del JSX.
✅Cómo verificar: buscar algo que no existe (ej. "xyz") debe mostrar el mensaje "No se encontraron productos con ese nombre." en vez de dejar la pantalla en blanco.
🚀 Recordatorio: estos ejercicios (límite del contador, contador de resultados, mensaje vacío) son de práctica — se pueden dejar en el proyecto, no afectan el entregable de la guía 02.
