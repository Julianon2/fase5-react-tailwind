Paso 1 · Mecánica

Crear src/Contador.jsx

Antes de tocar el catálogo real, se practica useState en un componente nuevo y aislado — así cualquier error se queda contenido ahí, sin afectar el proyecto.

1

En src/, crear el archivo Contador.jsx (al lado de App.jsx, Navbar.jsx, etc.).

2

Escribir el componente completo:

frontend-react/src/Contador.jsxcontenido completo
import { useState } from 'react'

function Contador() {
  const [cuenta, setCuenta] = useState(0)

  return (
    <div className="flex flex-col items-center gap-3 p-6 bg-white rounded-xl shadow-md">
      <p className="text-4xl font-extrabold text-verde">{cuenta}</p>
      <div className="flex gap-3">
        <button
          onClick={() => setCuenta(cuenta - 1)}
          className="w-10 h-10 bg-slate-200 rounded-lg font-bold text-xl"
        >
          −
        </button>
        <button
          onClick={() => setCuenta(cuenta + 1)}
          className="w-10 h-10 bg-verde text-white rounded-lg font-bold text-xl"
        >
          +
        </button>
      </div>
    </div>
  )
}

export default Contador
ParteQué hace
import { useState } from 'react'Trae el Hook — obligatorio en todo archivo que lo use
useState(0)Crea la caja de estado, con valor inicial 0
{cuenta}Muestra el valor actual en pantalla
onClick={() => setCuenta(cuenta + 1)}Al hacer clic en "+", suma 1 al valor guardado
onClick={() => setCuenta(cuenta - 1)}Al hacer clic en "−", resta 1 — sin límite todavía, puede bajar a negativos
⚠️Formatea el archivo con Shift + Alt + F si la indentación queda desordenada al pegar.
3

En App.jsx, importar Contador y usarlo temporalmente dentro del <main>, justo después de <Navbar /> — es solo para probarlo, se quita en el Paso 4:

frontend-react/src/App.jsxagregar temporalmente
import Contador from './Contador.jsx'  // agregar junto a los otros imports

// ...dentro del return, justo después de <Navbar />:
<Contador />
✅Cómo verificar: en localhost:5173, debajo del navbar aparece una tarjeta con el número 0 y dos botones. Hacer clic en "+" suma, hacer clic en "−" resta — el número cambia en pantalla en tiempo real.

Paso 3 · Filtrado

Filtrar el catálogo con filter() + map()

Último paso: usar busqueda para decidir, antes del .map() de S22, cuáles productos se dibujan.

1

Localizar, dentro del <section className="grid ...">> del catálogo, el productos.map(...) de S22 — en tu proyecto se ve así:

frontend-react/src/App.jsxantes
{productos.map((p) => (
  <ProductCard
    key={p.nombre}
    nombre={p.nombre}
    descripcion={p.descripcion}
    precio={p.precio}
    imagen={p.imagen}
    stock={p.stock}
  />
))}

Agregar .filter(...) justo antes del .map(...) — el resto de las props no cambia:

frontend-react/src/App.jsxdespués
{productos
  .filter((p) => p.nombre.toLowerCase().includes(busqueda.toLowerCase()))
  .map((p) => (
    <ProductCard
      key={p.nombre}
      nombre={p.nombre}
      descripcion={p.descripcion}
      precio={p.precio}
      imagen={p.imagen}
      stock={p.stock}
    />
  ))}
ParteQué hace
.filter((p) => ...)Por cada producto, se queda solo si la condición es verdadera
p.nombre.toLowerCase()El nombre del producto, convertido a minúsculas
.includes(busqueda.toLowerCase())Verdadero si el nombre contiene lo que se escribió, también en minúsculas
.filter(...).map(...)Encadenados: primero se reduce la lista, después se convierte en tarjetas
💡Si prefieres escribirlo en dos pasos en vez de encadenado, también es válido: const visibles = productos.filter(...) arriba, y luego visibles.map(...) en el JSX — el resultado es el mismo.
✅Cómo verificar: al escribir "mouse" en el input, solo queda visible la tarjeta del Mouse Inalámbrico. Al borrar el texto, las 4 tarjetas vuelven a aparecer.
Paso 4 · Verificación

Confirmar que todo funciona

<Contador /> se queda por ahora en App.jsx, visible encima del catálogo — sigue siendo útil como ejemplo en pantalla. Este paso es solo de verificación.

1

Abrir localhost:5173 y probar el flujo completo: escribir "teclado" — debe quedar solo esa tarjeta. Escribir algo que no existe (ej. "xyz") — el catálogo debe quedar completamente vacío, sin errores. Borrar todo el texto — las 4 tarjetas deben volver.

2

Revisar la consola del navegador (F12 → Console) y la terminal de Vite — ninguna debe mostrar errores rojos.

✅Cómo verificar: el buscador filtra en vivo, sin recargar la página, y el catálogo vacío (al buscar algo que no existe) no rompe nada — solo no muestra tarjetas.
