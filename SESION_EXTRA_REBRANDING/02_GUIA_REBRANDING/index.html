Paso 2

Cargar las 4 fuentes en index.html

1

Abrir frontend-react/index.html (en la raíz de frontend-react/, no dentro de src/). Así se ve ahora mismo:

frontend-react/index.htmlantes
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" type="image/svg+xml" href="/favicon.svg" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>frontend-react</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>

Reemplazar todo el archivo por esto (título real + enlaces de Google Fonts agregados dentro de <head>):

frontend-react/index.htmldespués
<!doctype html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" type="image/svg+xml" href="/favicon.svg" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>TechStore Pro</title>
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Michroma&family=Space+Grotesk:wght@500;600;700&family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500;700&display=swap" />
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>
ParteQué hace
lang="es"Corrige el idioma del documento (estaba en inglés por defecto de Vite)
<title>Cambia la pestaña del navegador de "frontend-react" a "TechStore Pro"
rel="preconnect"Le dice al navegador que se prepare para conectar a Google Fonts antes de necesitarlo — carga más rápida
family=Michroma&family=...Una sola URL pide las 4 familias de una vez, separadas por &family=. Debe ir completa en una sola línea, sin saltos de línea ni espacios dentro de la URL
display=swapMientras la fuente carga, muestra texto con una fuente del sistema en vez de dejarlo invisible
La URL de Google Fonts NO puede estar partida en varias líneas. El <link rel="stylesheet" ...> de las fuentes debe ir completo en una sola línea. Si el editor (o el formateador con Shift + Alt + F) la parte en varias líneas, quedan espacios dentro de la URL y Google Fonts responde error 400: las fuentes no cargan y el navegador usa otras del sistema sin avisar, sin mostrar ningún error en pantalla. Si ya la tienes partida, reemplázala por la línea completa del bloque "después".
Cómo verificar: abre F12 → pestaña Network, escribe css2 en el filtro y recarga con Ctrl + Shift + R. La petición a fonts.googleapis.com debe decir 200, no 400.
Paso 3

Reemplazar el ícono de la pestaña (favicon)

1

En tu editor de código, dentro de la carpeta del proyecto, abrir la carpeta frontend-react/public/ — ahí (no dentro de src/) ya existe un archivo llamado favicon.svg. Es el logo genérico morado/azul que trae la plantilla de Vite por defecto — no tiene nada que ver con TechStore Pro.

Hacer clic en favicon.svg para abrirlo — aunque termine en .svg, es un archivo de texto plano (código XML) y se edita igual que un .jsx o .css.

⚠️Si se abre como imagen (vista previa visual, con un panel que dice "Image Preview") en vez de mostrar el código: clic derecho sobre favicon.svg en el explorador de archivos → "Open With..." ("Abrir con...") → elegir "Text Editor" ("Editor de texto"). Así se abre el código XML en vez de la imagen renderizada.

Una vez abierto en modo texto, seleccionar todo su contenido (Ctrl+A) y reemplazarlo completo por esto:

frontend-react/public/favicon.svgarchivo completo
<svg xmlns="http://www.w3.org/2000/svg" width="32" height="32" viewBox="0 0 32 32">
  <rect width="32" height="32" rx="7" fill="#0A0A0A"/>
  <circle cx="16" cy="16" r="6" fill="#FF4B2B"/>
</svg>
ParteQué hace
rect rx="7"Fondo cuadrado negro con esquinas redondeadas — mismo radio moderado del resto de la identidad
circle fill="#FF4B2B"El punto coral centrado — el mismo acento de marca que el "." del wordmark
💡El archivo index.html (Paso 2) ya tiene la línea <link rel="icon" type="image/svg+xml" href="/favicon.svg"> apuntando a esta misma ruta — no hay que cambiar esa línea, solo el contenido del archivo SVG.
2

Guardar el archivo. Si el servidor de frontend no está corriendo todavía, levantarlo:

terminal — dentro de frontend-react/
npm run dev

Abrir localhost:5173 en el navegador. El favicon es uno de los recursos que el navegador más agresivamente guarda en caché — si después de recargar normal (F5) la pestaña sigue mostrando el logo morado viejo, hacer una recarga forzada: Ctrl + Shift + R (Windows) o Cmd + Shift + R (Mac).

✅Cómo verificar: el ícono en la pestaña del navegador debe mostrar un cuadrado negro con un punto coral centrado, no el logo morado/azul de Vite.

Paso 5

Verificar en el navegador

1

Levantar el servidor de frontend si no está corriendo:

terminal — dentro de frontend-react/
npm run dev
2

Abrir localhost:5173 y verificar:

  • La pestaña del navegador dice "TechStore Pro", no "frontend-react"
  • El ícono de la pestaña ya no es el logo morado/azul de Vite — ahora es el cuadrado negro con el punto coral
  • Abrir las herramientas de desarrollador (F12) → pestaña Network → recargar → deben aparecer peticiones a fonts.googleapis.com y fonts.gstatic.com cargando sin error
  • El sitio puede verse "roto" visualmente (textos sin color, verde ya no aparece) — es esperado, se corrige página por página desde la Sesión 27
✅Cómo verificar que las fuentes sí cargaron: en la consola del navegador, ejecutar document.fonts.check("16px Michroma") — debe devolver true.
