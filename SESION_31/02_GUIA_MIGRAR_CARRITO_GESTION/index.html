¿Qué construimos hoy?
El carrito se puede gestionar

Hasta hoy el carrito solo sumaba productos. Ahora tiene su propia página, /carrito, donde se cambian cantidades, se quitan productos, se vacía con confirmación y se ve el total. Para sumar hay que convertir el precio de texto a número. Y el botón de pagar sabe si hay sesión: sin ella te lleva al login y, al entrar, te devuelve al carrito.

Paso 1 · Preparación

Dejar el carrito guardado en blanco

Hoy el carrito guarda cada producto como una fila suelta. Desde esta sesión cada fila lleva un campo nuevo, cantidad. Un carrito guardado con la forma vieja no tiene ese campo y la página nueva mostraría NaN (no es un número). Por eso, antes de cambiar nada, se vacía el carrito que tengas guardado.

1

Levanta el frontend (esta sesión no toca el backend, pero lo necesitarás en el Paso 6 para iniciar sesión):

terminal 1 — dentro de frontend-react/
npm run dev
terminal 2 — dentro de backend/ (déjalo encendido para el Paso 6)
npm run dev
Cómo verificar: localhost:5173 muestra la tienda y la terminal del backend dice que conectó a MongoDB. Local o Atlas da igual: hoy no se crea ni se borra nada en la base.
2

Mira cómo está tu carrito hoy y vacíalo. En la tienda pulsa Vaciar junto a "Carrito ( N )" del Navbar (aparece solo si hay productos). Si el carrito ya está en cero, no verás el botón y no hace falta hacer nada.

Después abre las herramientas del navegador con F12, pestaña Application, y en la columna izquierda Local Storage → http://localhost:5173.

Cómo verificar: en la lista no existe la clave carrito. Si todavía aparece, el carrito no quedó vacío: vuelve a pulsar Vaciar y recarga con F5.
Esa clave carrito es donde el navegador guarda tu compra para que no se pierda al recargar. En el Paso 3 vas a verla cambiar de forma.
Paso 2 · El precio

Un precio que es texto no se puede sumar

Para calcular el total hay que sumar precios. Pero en tu base el precio es texto: "$8.999.000". Primero lo compruebas con tus propios ojos y después escribes dos pequeñas funciones que lo convierten de texto a número y de número a texto.

1

Mira la trampa antes de arreglarla. En la tienda abre F12, pestaña Console, y escribe estas líneas, una por una, pulsando Enter en cada una:

consola del navegador (F12 → Console)
Number("$8.999.000")
parseFloat("8.999.000")
"$1.000" + "$2.000"
Number("8999000")
(8999000).toLocaleString("es-CO")
Cómo verificar: te responde, en este orden: NaN, 8.999, "$1.000$2.000", 8999000 y "8.999.000". Tres trampas: el $ y los puntos hacen que Number no entienda el texto; parseFloat entiende el primer punto como decimal y devuelve 8,999 en lugar de 8 millones; y sumar dos textos con + los pega, no los suma.
NaN significa "Not a Number" (no es un número). Si alguna vez ves NaN en la pantalla de la tienda, casi siempre es un texto que se intentó usar como número.
2

La solución es quitar del texto todo lo que no son dígitos (el $ y los puntos) y convertir lo que queda. Este es el primer archivo .js del proyecto: hasta ahora todo terminaba en .jsx. Lleva .js porque solo tiene funciones, sin JSX; los componentes siguen siendo .jsx. Para mantener el orden, las funciones auxiliares van en su propia carpeta: dentro de src, crea una carpeta nueva llamada utils (clic derecho sobre src → New Folder). Dentro de utils crea el archivo precio.js con este contenido completo:

frontend-react/src/utils/precio.jsarchivo nuevo — contenido completo
// El precio llega como texto: "$8.999.000". Para sumar hay que volverlo número.
export function precioANumero(precio) {
  return Number(precio.replace(/[$.]/g, ""));
}

// Y para mostrarlo, de número otra vez a texto con puntos: 8999000 -> "$8.999.000"
export function formatearPrecio(numero) {
  return "$" + numero.toLocaleString("es-CO");
}
ParteQué hace
export function precioANumero(precio)Recibe el texto "$8.999.000" y devuelve el número 8999000. Se escribe con export para poder importarla desde otros archivos
precio.replace(/[$.]/g, "")Reemplaza por nada ("") cada $ y cada .. Es una expresión regular: los corchetes [ ] dicen "cualquiera de estos caracteres" y la g final significa "en todo el texto, no solo el primero"
Number("8999000")Ya sin símbolos, Number sí entiende el texto y lo vuelve un número real que se puede sumar y multiplicar
export function formatearPrecio(numero)Hace el camino de vuelta: de 8999000 a "$8.999.000", para mostrarlo en pantalla
numero.toLocaleString("es-CO")Escribe el número con las costumbres de Colombia (es-CO): puntos para separar los miles. Por eso 8999000 queda "8.999.000"
"$" + ...Pega el signo $ adelante, porque toLocaleString solo trae los números
Todavía nadie importa este archivo, así que no verás ningún cambio en la tienda. Se usa en el Paso 4.
Paso 3 · CartContext

Una fila por producto, con su cantidad

Hoy, agregar el mismo producto tres veces crea tres filas iguales. Un carrito de verdad muestra una fila con cantidad 3. CartContext aprende tres cosas: contar cantidad, cambiarla con más y menos, y quitar un producto por su id (no por su posición).

1

Este es tu CartContext.jsx real, completo, tal como está hoy:

frontend-react/src/CartContext.jsxantes
import { createContext, useState } from "react";

export const CartContext = createContext();

export function CartProvider({ children }) {
  const [items, setItems] = useState(() => {
    const guardado = localStorage.getItem("carrito");
    return guardado ? JSON.parse(guardado) : [];
  });

  function agregarAlCarrito(producto) {
    const nuevo = [...items, producto];
    setItems(nuevo);
    localStorage.setItem("carrito", JSON.stringify(nuevo));
  }

  function quitarDelCarrito(indice) {
    const nuevo = items.filter((_, i) => i !== indice);
    setItems(nuevo);
    localStorage.setItem("carrito", JSON.stringify(nuevo));
  }

  function vaciarCarrito() {
    setItems([]);
    localStorage.removeItem("carrito");
  }

  return (
    <CartContext.Provider
      value={{ items, agregarAlCarrito, quitarDelCarrito, vaciarCarrito }}
    >
      {children}
    </CartContext.Provider>
  );
}

import { createContext, useState, useEffect } from "react";

export const CartContext = createContext();

export function CartProvider({ children }) {
  const [items, setItems] = useState(() => {
    const guardado = localStorage.getItem("carrito");
    return guardado ? JSON.parse(guardado) : [];
  });

  // Cada vez que cambia el carrito, se guarda solo
  useEffect(() => {
    localStorage.setItem("carrito", JSON.stringify(items));
  }, [items]);

  function agregarAlCarrito(producto) {
    const existe = items.find((item) => item.id === producto.id);
    if (existe) {
      setItems(
        items.map((item) =>
          item.id === producto.id ? { ...item, cantidad: item.cantidad + 1 } : item,
        ),
      );
    } else {
      setItems([...items, { ...producto, cantidad: 1 }]);
    }
  }

  function cambiarCantidad(id, cambio) {
    setItems(
      items.map((item) =>
        item.id === id ? { ...item, cantidad: item.cantidad + cambio } : item,
      ),
    );
  }

  function quitarDelCarrito(id) {
    setItems(items.filter((item) => item.id !== id));
  }

  function vaciarCarrito() {
    setItems([]);
  }

  return (
    <CartContext.Provider
      value={{ items, agregarAlCarrito, cambiarCantidad, quitarDelCarrito, vaciarCarrito }}
    >
      {children}
    </CartContext.Provider>
  );
}

ParteQué hace
import { createContext, useState, useEffect }Se suma useEffect, el hook que ejecuta código después de que algo cambia
useEffect(() => { localStorage.setItem(...) }, [items])Cada vez que items cambia, el carrito se guarda solo. Antes cada función guardaba a mano, y era fácil olvidarlo en una. Ahora hay un solo lugar que guarda. El [items] del final dice "vigila esto"
items.find((item) => item.id === producto.id)Busca si el producto ya está en el carrito, comparando por id. Devuelve la fila si existe, o undefined si no
items.map(... { ...item, cantidad: item.cantidad + 1 })Si ya existía, no se modifica la fila: se crea una copia con la cantidad subida (...item copia todos los campos y el siguiente los pisa). map devuelve una lista nueva donde solo cambió esa fila
[...items, { ...producto, cantidad: 1 }]Si no existía, se hace una lista nueva con todo lo anterior más el producto con cantidad: 1
function cambiarCantidad(id, cambio)Sirve para el botón + (cambio de 1) y el botón − (cambio de -1). Una sola función en lugar de dos
items.filter((item) => item.id !== id)Quitar un producto: deja pasar todas las filas menos la del id indicado. Antes se identificaba por posición (indice), y la posición cambia cada vez que se quita algo; el id no cambia
setItems([])vaciarCarrito ya no borra el localStorage a mano: al quedar items vacío, el useEffect guarda [] solo
Regla de React que se cumple en todo el archivo: nunca se modifica la lista existente, siempre se crea una nueva ([...items, x], map, filter). React compara la lista vieja con la nueva para saber si debe redibujar. Si cambias la misma lista por dentro, no se entera.

Paso 4 · La página

La página del carrito y su ruta

Ahora se construye la página donde el cliente revisa su compra: la lista, los botones para cambiar cantidades, el total, y qué pasa al pagar. Es un archivo nuevo, Carrito.jsx, y se registra su dirección /carrito en App.jsx.

1

Crea el archivo src/Carrito.jsx con este contenido completo. Es largo; copia todo:

import { useState, useContext } from "react";
import { Link, useNavigate } from "react-router-dom";
import { CartContext } from "./CartContext.jsx";
import { AuthContext } from "./AuthContext.jsx";
import { precioANumero, formatearPrecio } from "./utils/precio.js";

function Carrito() {
  const { items, cambiarCantidad, quitarDelCarrito, vaciarCarrito } =
    useContext(CartContext);
  const { usuario } = useContext(AuthContext);
  const navegar = useNavigate();
  const [confirmando, setConfirmando] = useState(false);

  const unidades = items.reduce((suma, item) => suma + item.cantidad, 0);
  const total = items.reduce(
    (suma, item) => suma + precioANumero(item.precio) * item.cantidad,
    0,
  );

  function irAIngresar() {
    navegar("/login", {
      state: { aviso: "Inicia sesión para continuar con tu compra", desde: "/carrito" },
    });
  }

  if (items.length === 0) {
    return (
      <section className="max-w-md mx-auto text-center flex flex-col items-center gap-5 py-16">
        <h1 className="font-display font-bold text-4xl tracking-tighter">
          Tu carrito está vacío<span className="text-accent">.</span>
        </h1>
        <p className="text-gray-700">Agrega productos desde el catálogo y aparecerán aquí.</p>
        <Link
          to="/productos"
          className="bg-ink text-paper px-6 py-3 rounded-card text-sm font-semibold hover:bg-accent transition-colors"
        >
          Ver productos
        </Link>
      </section>
    );
  }

  return (
    <div className="flex flex-col gap-8">
      <section>
        <p className="font-mono text-xs uppercase tracking-widest text-gray-500">Compra</p>
        <h1 className="font-display font-bold text-5xl tracking-tighter mt-4">
          Tu carrito<span className="text-accent">.</span>
        </h1>
      </section>

      <div className="grid lg:grid-cols-[1fr_320px] gap-10 items-start">
        <ul className="flex flex-col divide-y divide-gray-300">
          {items.map((item) => (
            <li key={item.id} className="flex flex-wrap items-center gap-4 py-5">
              <img
                src={item.imagen}
                alt={item.nombre}
                className="size-20 rounded-card object-cover bg-gray-100"
              />
              <div className="flex-1 min-w-40">
                <p className="font-semibold">{item.nombre}</p>
                <p className="font-mono text-sm text-gray-700">{item.precio}</p>
              </div>

              <div className="flex items-center gap-3">
                <button
                  onClick={() => cambiarCantidad(item.id, -1)}
                  disabled={item.cantidad === 1}
                  aria-label={"Quitar una unidad de " + item.nombre}
                  className="size-8 rounded-full border border-gray-300 hover:border-ink disabled:opacity-30 disabled:hover:border-gray-300"
                >
                  −
                </button>
                <span className="font-mono w-6 text-center">{item.cantidad}</span>
                <button
                  onClick={() => cambiarCantidad(item.id, 1)}
                  aria-label={"Agregar una unidad de " + item.nombre}
                  className="size-8 rounded-full border border-gray-300 hover:border-ink"
                >
                  +
                </button>
              </div>

              <div className="text-right min-w-28">
                <p className="font-mono font-bold">
                  {formatearPrecio(precioANumero(item.precio) * item.cantidad)}
                </p>
                <button
                  onClick={() => quitarDelCarrito(item.id)}
                  className="text-xs text-accent-dark underline"
                >
                  Quitar
                </button>
              </div>
            </li>
          ))}
        </ul>

        <aside className="bg-gray-50 rounded-card p-6 flex flex-col gap-4">
          <h2 className="font-display font-bold text-xl">Resumen</h2>
          <div className="flex justify-between text-sm text-gray-700">
            <span>Unidades</span>
            <span className="font-mono">{unidades}</span>
          </div>
          <div className="flex justify-between items-baseline border-t border-gray-300 pt-4">
            <span className="font-semibold">Total</span>
            <span className="font-mono text-2xl font-bold">{formatearPrecio(total)}</span>
          </div>

          {usuario ? (
            <>
              <p className="text-sm text-gray-700">
                Compra a nombre de <strong>{usuario}</strong>.
              </p>
              <button
                disabled
                className="bg-ink text-paper py-3 rounded-card text-sm font-semibold opacity-40 cursor-not-allowed"
              >
                Pagar con Wompi (próximamente)
              </button>
            </>
          ) : (
            <button
              onClick={irAIngresar}
              className="bg-ink text-paper py-3 rounded-card text-sm font-semibold hover:bg-accent transition-colors"
            >
              Inicia sesión para pagar
            </button>
          )}

          {confirmando ? (
            <div className="flex items-center gap-3 text-sm">
              <span>¿Vaciar todo el carrito?</span>
              <button
                onClick={() => {
                  vaciarCarrito();
                  setConfirmando(false);
                }}
                className="text-accent-dark font-semibold underline"
              >
                Sí, vaciar
              </button>
              <button onClick={() => setConfirmando(false)} className="underline">
                No
              </button>
            </div>
          ) : (
            <button
              onClick={() => setConfirmando(true)}
              className="text-sm text-gray-700 underline text-left"
            >
              Vaciar carrito
            </button>
          )}

          <Link to="/productos" className="text-sm text-gray-700 underline">
            Seguir comprando
          </Link>
        </aside>
      </div>
    </div>
  );
}

export default Carrito;

const URL_API = "http://localhost:3000/api/auth";

const FORM_VACIO = { email: "", password: "" };

function Login() {
  const { login } = useContext(AuthContext);
  const navegar = useNavigate();
  const ubicacion = useLocation();
  const aviso = ubicacion.state ? ubicacion.state.aviso : null;
  const [form, setForm] = useState(FORM_VACIO);
  const [errores, setErrores] = useState({});
  const [estado, setEstado] = useState("inactivo");
  const [mensajeError, setMensajeError] = useState("");

  function manejarCambio(e) {
    setForm({ ...form, [e.target.name]: e.target.value });
    setErrores({ ...errores, [e.target.name]: "" });
    if (estado !== "inactivo") setEstado("inactivo");
  }

  function validar() {
    const nuevos = {};
    if (!/^\S+@\S+\.\S+$/.test(form.email)) {
      nuevos.email = "Escribe un correo válido, como nombre@correo.com";

    if (!form.password) {

      setEstado("error");

  return (

        </p>
      )}

      <form onSubmit={manejarEnvio} noValidate className="flex flex-col gap-5">
        <Campo etiqueta="Correo electrónico" nombre="email" error={errores.email}>
          <input
            id="email"
            name="email"
            type="email"
            value={form.email}
            onChange={manejarCambio}
            placeholder="tucorreo@ejemplo.com"
            autoComplete="email"
            className={claseInput(errores.email)}
          />
        </Campo>

        <Campo etiqueta="Contraseña" nombre="password" error={errores.password}>
          <input
            id="password"
            name="password"
            type="password"
            value={form.password}
            onChange={manejarCambio}
            placeholder="Tu contraseña"
            autoComplete="current-password"
            className={claseInput(errores.password)}
          />
        </Campo>

        <button
          type="submit"
          disabled={estado === "enviando"}
          className="bg-ink text-paper px-7 py-3.5 rounded-card text-sm font-semibold enabled:hover:bg-accent transition-colors disabled:opacity-50 disabled:cursor-not-allowed"
        >
          {estado === "enviando" ? "Entrando..." : "Entrar →"}
        </button>

        {estado === "error" && (
          <p role="alert" className="bg-gray-50 rounded-card p-4 text-sm font-semibold text-accent-dark">
            {mensajeError}
          </p>
        )}
      </form>

      <p className="text-sm text-gray-700">
        ¿No tienes cuenta?{" "}
        <Link to="/registro" className="font-semibold underline hover:text-accent transition-colors">
          Regístrate
        </Link>
      </p>
    </div>
  );
}
